# Be excellent to each other

Be kind, specific and useful. Critique code and ideas, not people. Beginners,
experienced contributors and people who only came for the `git log` joke are welcome.

No harassment, discrimination, threats, doxxing, unwanted contact, spam or sharing
somebody's private chats/credentials. Respect a request to stop. Friendly jokes
are welcome; making someone the target is not.

This applies to project issues, pull requests, discussions and other spaces run
by the maintainers. Maintainers may edit/remove harmful content, close threads
or restrict participation. Decisions should be proportionate and protect the
people involved, not punish good-faith disagreement.

Report abusive GitHub content using GitHub's reporting tools or contact a maintainer
privately through their GitHub profile. Do not repeat private information in a
public report. Vulnerability reports follow [SECURITY.md](SECURITY.md).
